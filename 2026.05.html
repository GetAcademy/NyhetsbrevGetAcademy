Fra IT-interesse til IT-jobb

Hei,

GET Academy har et helhetlig løp for kandidater som er nysgjerrige på IT og programmering, men som trenger en praktisk og trygg vei videre mot kompetanse, praksis og jobb.

Vi jobber etter modellen Start → Fordypning → Praksis → Jobb, med ulike innganger avhengig av kandidatens situasjon, forkunnskaper og formelle opptaksgrunnlag.

1Start – neste mulighet fra 10. august

Første steg i løpet er grunnleggende programmering og IT-utvikling. Her finnes det to hovedveier inn: Start IT og fagskoleutdanningen Introduksjon til programmering og IT-utvikling.

Kurs

Start IT

  • Åpent for alle
  • Oppstart 10. august
  • Pris: 63 000 kr
  • Passer for kandidater som ikke oppfyller opptakskrav til fagskole
  • Kan tas som fullt løp eller modulvis
Fagskoleutdanning

Introduksjon til programmering og IT-utvikling

  • Gir studiepoeng
  • Oppstart 10. august
  • Egenbetaling: 5 000 kr
  • Har formelle opptakskrav
  • Faglig innhold tilsvarer Start IT-løpet

Har kandidaten opptaksgrunnlag? Da bør fagskoleutdanningen vurderes først.
Har kandidaten ikke opptaksgrunnlag? Da kan Start IT eller realkompetansevei være aktuelt.

1 Modulvis Start IT / realkompetansevei

Det er også mulig å starte med første del av Start IT. Dette kan være aktuelt for kandidater som ønsker å teste retningen mer forpliktende, eller som trenger realkompetanse for å søke seg inn på fagskole senere.

  • Første del varer 7 uker
  • Pris: 21 000 kr
  • Kan gi grunnlag for å søke opptak til fagskole via realkompetanse
  • Resten av Start IT kan tas videre modulvis

Realkompetanse vurderes av hver enkelt fagskole. Kandidaten må fylle minst 23 år i opptaksåret.

2 Fordypning våren 2027

Etter startfasen kan kandidaten gå videre til fordypning. Målet er å tilby to retninger våren 2027: frontend og backend.

  • Frontend er etablert som fagskoleutdanning og har vært kjørt flere ganger
  • Backend har vært kjørt som kurs
  • Vi forventer å kunne tilby backend som fagskoleutdanning våren 2027
  • Finansiering/driftsstøtte er ikke endelig avklart

3 Praksis og 4 jobb

Etter start og fordypning jobber GET Academy for å finne relevant praksisbedrift. Målet er praksisoppstart august 2027, eller så snart som mulig etterpå.

  • Praksis har ikke kostnad for kandidaten
  • Vi følger opp både kandidat og bedrift
  • I noen tilfeller kan det også være mulig å gå direkte fra Start IT eller Intro til praksis, hvis vi ser en god match med en bedrift

Vi kan ikke garantere praksisplass, men vi jobber aktivt med å finne relevante bedrifter når kandidaten er klar.

Gratis introduksjonskurs
